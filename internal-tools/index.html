Quick answer

What is an internal tool?

An internal tool is software used by employees to perform recurring business work more reliably. It might manage requests, coordinate approvals, combine information from several systems, track exceptions, generate outputs, or give employees a focused interface for a process that general-purpose software does not handle well.

Not every internal process needs an app, sometimes a spreadsheet is exactly the right tool. In other cases the existing software is fine and the real problem is that two systems don’t talk to each other, or a bit of configuration or automation removes most of the friction.

Instead of asking “Can we build an internal tool?” ask “What is the simplest system that makes this work reliably?”
