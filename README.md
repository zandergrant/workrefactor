# workrefactor

## Editorial standard

How Work Runs is written in a grounded, conversational voice informed by real operating experience. Use first person when sharing the founder's perspective and a consistent business voice when describing services. Prefer complete, connected sentences, concrete examples, contractions where natural, and clear descriptions of what people actually do. Avoid em dashes in prose, generic consulting jargon, exaggerated claims, repetitive contrast formulas, and unnecessary marketing fragments. Keep useful short labels, headings, and interface instructions concise.

Preserve the existing search intent, page URLs, metadata, internal links, structured data, technical instructions, factual qualifications, and accessibility when editing. Keep previous in-house work distinct from consultancy client engagements.
