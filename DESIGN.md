# How Work Runs: frontend design direction

Updated 2026-10-30 using the principles of Anthropic's [frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design).

## Purpose
Explain practical operations consulting to founders and operations leaders, then help them make a project inquiry. Content and navigation should stay plainspoken and easy to understand.

## Visual position
**Operational clarity.** The homepage opens with a recognizable workflow rather than abstract technology imagery or decorative gradients. Typography is DM Sans throughout: clear enough for extended practical guides, with bold hierarchy on primary pages.

## Palette
- Ink and navigation: `#112E38`
- Body text: `#17313A`
- Working accent: `#246B73`
- Tinted working surface: `#E4F0EF`
- Hero canvas: `#EDF3F3`
- Rules and boundaries: `#D1DFE0`

## Conventions
- All visual styles live in `styles.css`; JavaScript is reserved for behavior.
- Use labels and numbers only where they add information (e.g. actual process stages).
- Avoid decorative glows, headline word-highlighting, generic shadows, excessive motion, and card grids that obscure hierarchy.
- Keep the five resource URLs, contact form functionality, and readable long-form guides.
- Don't present illustrative workflow visuals as client case studies or claim unverified outcomes.
- Use visible keyboard focus, mobile layouts, adequate contrast, and reduced-motion support.
